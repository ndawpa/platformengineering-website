## Quando escolher Minikube

Minikube é conveniente para desenvolvimento local, addons e recursos que se beneficiam de uma experiência integrada. Para CI e clusters descartáveis multi-node, kind costuma ser mais simples.

## Instalar

No macOS e Linux com Homebrew:

```bash
brew install minikube
minikube version
```

No Windows use `winget install Kubernetes.minikube`. A documentação oficial também fornece binários e pacotes por arquitetura.

## Iniciar um perfil explícito

```bash
minikube start --profile estudos --driver=docker --cpus=2 --memory=4096
minikube profile estudos
kubectl get nodes
minikube status --profile estudos
```

## Addons e acesso a serviços

```bash
minikube addons list --profile estudos
minikube addons enable metrics-server --profile estudos
kubectl top nodes
```

Para um Service NodePort, prefira `minikube service NOME --url` em vez de assumir que o IP é acessível em todos os sistemas.

## Diagnóstico e limpeza

```bash
minikube logs --profile estudos
minikube stop --profile estudos
minikube delete --profile estudos
```
