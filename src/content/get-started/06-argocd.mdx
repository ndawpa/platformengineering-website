## Confirmar o alvo

```bash
kubectl config current-context
kubectl get nodes
```

Não continue se o contexto apontar para produção.

## Instalar os componentes

```bash
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
kubectl wait --for=condition=Available deployment --all -n argocd --timeout=300s
kubectl get pods -n argocd
```

O branch `stable` simplifica aprendizado, mas produção deve fixar uma versão revisada para garantir reprodutibilidade.

## Instalar e validar a CLI

Use o método oficial do seu sistema na seção CLI Installation. Depois:

```bash
argocd version --client
kubectl port-forward service/argocd-server -n argocd 8080:443
```

Em outro terminal, obtenha a senha inicial e faça login local:

```bash
argocd admin initial-password -n argocd
argocd login localhost:8080 --insecure
argocd cluster list
```

Troque a senha e remova o Secret inicial após validar o acesso.

## Troubleshooting e remoção

```bash
kubectl get events -n argocd --sort-by=.lastTimestamp
kubectl logs -n argocd deployment/argocd-server
kubectl delete namespace argocd
```
