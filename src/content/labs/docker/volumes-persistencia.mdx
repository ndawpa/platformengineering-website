## Gravar e localizar o volume
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/docker/volumes
make setup
docker volume ls
make verify
```
## Recriar containers sem apagar dados
```bash
make recreate
make verify
```
`docker compose down` remove containers e rede, mas preserva o volume. A opção `--volumes` é deliberadamente destrutiva.
## Limpar
```bash
make cleanup
```

<details>
<summary>Desafio de extensão</summary>

Execute o writer com UID `10001`, provoque uma falha de permissão no volume, diagnostique owner e mode dentro de um container descartável e corrija sem usar `chmod 777`. Depois demonstre a diferença entre `down` e `down --volumes`.
