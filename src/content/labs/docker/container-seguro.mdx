## Construir e inspecionar
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/docker/container-seguro
make setup
docker compose exec app id
docker inspect docker-secure-app --format '{{json .HostConfig}}'
```
## Testar as restrições
```bash
docker compose exec app sh -c 'touch /blocked'
docker compose exec app sh -c 'touch /tmp/allowed && ls -l /tmp/allowed'
make verify
```
A raiz é somente leitura, mas `/tmp` é um `tmpfs` gravável. O processo usa UID não-root, não recebe novas permissões e perde todas as capabilities.
## Limpar
```bash
make cleanup
```
