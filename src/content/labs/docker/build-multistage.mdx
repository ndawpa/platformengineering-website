## Construir a imagem
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/docker/multistage
make setup
docker history pe-lab/multistage:local
```
Compare o estágio `builder` com a imagem final no `Dockerfile`. Apenas `/output` atravessa a fronteira.
## Validar e executar
```bash
make verify
docker run --rm -p 127.0.0.1:8080:8080 pe-lab/multistage:local
```
Em outro terminal, acesse `http://127.0.0.1:8080`. Depois interrompa com `Ctrl+C` e execute `make cleanup`.

<details>
<summary>Desafio de extensão</summary>

Crie deliberadamente uma imagem single-stage contendo ferramentas de build, compare tamanho e `docker history`, examine as duas imagens com `docker image inspect` e restaure a versão multi-stage. Adicione um usuário não-root ao runtime e adapte a porta sem conceder capabilities.

</details>
