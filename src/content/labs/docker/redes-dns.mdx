## Subir e inspecionar
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/docker/networks
make setup
docker compose ps
docker network ls
docker compose exec client nslookup api
```
O serviço `api` não publica porta no host; somente o cliente na rede `backend` consegue alcançá-lo.
## Validar e limpar
```bash
make verify
docker compose exec client wget -qO- http://api:8080
make cleanup
```
