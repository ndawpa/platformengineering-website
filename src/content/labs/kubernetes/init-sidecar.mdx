## Preparar e acompanhar a inicialização
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/kubernetes/init-sidecar
make setup
kubectl describe pod web -n pe-multicontainer
```
Inspecione cada container e os volumes compartilhados:
```bash
kubectl logs -n pe-multicontainer web -c prepare
kubectl exec -n pe-multicontainer web -c web -- cat /usr/share/nginx/html/index.html
kubectl logs -n pe-multicontainer web -c log-reader
make verify
```

<details>
<summary>Desafio de extensão</summary>

Faça o init container encerrar temporariamente com código `1`, observe `initContainerStatuses` e prove que os containers principais não iniciam. Depois restaure o comando, adicione requests e limits ao sidecar e execute `make verify` novamente.

</details>

## Limpar
```bash
make cleanup
```
