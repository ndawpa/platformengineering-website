## Preparar e observar
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/kubernetes/jobs-cronjobs
make setup
kubectl get jobs,cronjobs,pods -n pe-jobs
kubectl logs -n pe-jobs job/report
```
O CronJob começa suspenso. Inspecione agenda, concorrência e históricos:
```bash
kubectl describe cronjob heartbeat -n pe-jobs
kubectl patch cronjob heartbeat -n pe-jobs --type=merge -p '{"spec":{"suspend":false}}'
kubectl create job --from=cronjob/heartbeat heartbeat-manual -n pe-jobs
kubectl logs -n pe-jobs job/heartbeat-manual
make verify
```
## Limpar

make cleanup
