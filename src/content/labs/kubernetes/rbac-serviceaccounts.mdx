## Preparar e testar permissões
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/kubernetes/rbac-serviceaccounts
make setup
kubectl auth can-i get pods -n pe-rbac --as=system:serviceaccount:pe-rbac:viewer
kubectl auth can-i list pods -n pe-rbac --as=system:serviceaccount:pe-rbac:viewer
```
A Role permite `get`, mas o objetivo exige também `list`. Use `kubectl auth can-i` e inspecione Role e RoleBinding antes de abrir a solução.

<details>
<summary>Dica e solução de referência</summary>
```bash
kubectl patch role pod-viewer -n pe-rbac --type=json -p='[
  {"op":"add","path":"/rules/0/verbs/-","value":"list"}
]'
make verify
```
</details>

Inspecione `RoleBinding` e confirme que o token não é montado automaticamente no ServiceAccount.
