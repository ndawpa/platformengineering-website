## Preparar e provocar uma rejeição
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/kubernetes/pod-security
make setup
kubectl run privileged -n pe-security --image=busybox:1.37.0 \
  --overrides='{"spec":{"containers":[{"name":"privileged","image":"busybox:1.37.0","securityContext":{"privileged":true}}]}}' \
  -- sleep 60
```
Leia a mensagem do admission controller e identifique violações de capabilities, usuário e seccomp.
## Aplicar a especificação segura
```bash
kubectl apply -f compliant-pod.yaml
kubectl get pod compliant -n pe-security -o yaml
make verify
```
## Limpar
```bash
make cleanup
```
