## Preparar o ambiente
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/kubernetes/storage-pvc
make setup
kubectl get storageclass,pv,pvc -n pe-storage
```
## Investigar o binding
```bash
kubectl describe pvc data -n pe-storage
kubectl exec -n pe-storage writer -- cat /data/message.txt
```
<details>
<summary>Dica e solução de referência</summary>

Exclua e recrie somente o pod usando o manifesto; o claim permanece:
```bash
kubectl delete pod writer -n pe-storage
kubectl apply -f exercise.yaml
make verify
```
</details>

## Limpar
```bash
make cleanup
```
