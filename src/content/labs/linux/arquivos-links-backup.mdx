## Resolver o desafio

Crie um symlink relativo, um hard link e um archive comprimido. Registre e compare inodes, tamanho aparente e destino dos links antes de validar.

<details>
<summary>Dicas e solução de referência</summary>

```bash
ln -s config/environment source/current-config
ln source/data.txt source/data.hardlink
stat source/data.txt source/data.hardlink
tar -czf backup/source.tar.gz source
tar -tzf backup/source.tar.gz
```
</details>
