## Coletar evidências
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/linux/networking
make setup
make shell
ip address
ip route
getent hosts api.internal
ss -lntp
curl -v http://api.internal:8080
```
Crie `/work/diagnostico.txt` registrando hostname, endereço resolvido, rota, socket, processo e resultado HTTP. Inclua literalmente `api.internal`. Diferencie falha de DNS, conexão recusada e timeout.

<details>
<summary>Dica e solução de referência</summary>
```bash
{ hostname; getent hosts api.internal; ss -lnt; curl -s http://api.internal:8080; } > /work/diagnostico.txt
```
</details>
