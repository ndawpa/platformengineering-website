## Preparar e investigar
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/linux/processos-sinais
make setup
make shell
```
Use `ps aux`, `ps -ef --forest`, `pgrep -af` e `/proc/<pid>/status`. Há um worker que grava datas e um processo `sleep` que deve ser preservado.
## Encerrar com segurança
Leia `/work/worker.pid`, correlacione PID, comando e arquivo aberto e envie o sinal menos destrutivo adequado. Não use `pkill` amplo.

<details>
<summary>Dicas e solução de referência</summary>
```bash
worker=$(cat /work/worker.pid)
kill -TERM "$worker"
sleep 1
kill -0 "$worker" 2>/dev/null || echo encerrado
```
</details>

exit
