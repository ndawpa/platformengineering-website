## Escrever o verificador
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/linux/shell-script
make setup
make shell
```
Crie `/work/check-services.sh`. Ele deve validar o argumento, suportar nomes com espaços, imprimir falhas em stderr, retornar `1` quando houver serviço unhealthy e `0` quando todos estiverem saudáveis.

<details>
<summary>Dicas e solução de referência</summary>
```bash
#!/usr/bin/env bash
set -euo pipefail
directory=${1:?uso: check-services.sh DIRETORIO}
failed=0
for service in "$directory"/*; do
  if [[ $(<"$service") != healthy ]]; then
    basename "$service"
    failed=1
  fi
done
exit "$failed"
```
</details>

## Validar e limpar
Salve, torne o arquivo executável e teste os dois caminhos:
```bash
chmod +x /work/check-services.sh
/work/check-services.sh /work/services; echo "$?"
exit
make verify
make cleanup
```
