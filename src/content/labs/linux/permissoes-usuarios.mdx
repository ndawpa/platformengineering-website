## Criar o ambiente isolado
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/linux/permissoes
make setup
make shell
```
Dentro do container, inspecione `ana`, `bruno` e `/work/projeto` com `id`, `ls -ld` e `stat`.
## Resolver o desafio
Adicione os dois usuários ao grupo `platform`. Altere o grupo do diretório e configure modo `2770`, preservando acesso apenas ao dono e grupo. Valide sua hipótese com `namei -l`, `stat` e `su` antes de abrir a solução.

<details>
<summary>Dicas e solução de referência</summary>
```bash
usermod -aG platform ana
usermod -aG platform bruno
chown -R root:platform /work/projeto
chmod 2770 /work/projeto
chmod 660 /work/projeto/config.txt
```
</details>

## Validar e limpar
```bash
exit
make verify
make cleanup
```
