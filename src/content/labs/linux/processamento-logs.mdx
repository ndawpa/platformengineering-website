## Executar o desafio
```bash
git clone https://github.com/ndawpa/platformengineering-website.git
cd platformengineering-website/labs/linux/texto-logs
make setup
make shell
cat /work/access.log
```
Crie `/work/report.txt` contendo apenas erros HTTP, agregados no formato `código quantidade`. O resultado esperado contém `500 2` e `404 1`.
Antes da solução, produza duas implementações: uma com `awk` e outra combinando `cut`, `sort` e `uniq`. Compare legibilidade e número de processos.

<details>
<summary>Dica e solução de referência</summary>
```bash
awk '$4 >= 400 { count[$4]++ } END { for (code in count) print code, count[code] }' /work/access.log | sort > /work/report.txt
```
</details>
